# Zuniga hub

Static family app. Upload this folder to a public GitHub repo and turn on Pages from the main branch, root.

Open the Pages URL in Safari on an iPhone. Share, Add to Home Screen, Add. Then open it from the icon.

Files:
- index.html — app, door, splash, setup
- manifest.json
- icon-180.png — home screen icon
- icon-512.png — door mark
- zuniga-hub-schema.sql — later, when there is a server
